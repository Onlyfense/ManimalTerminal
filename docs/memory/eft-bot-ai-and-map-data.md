Verified from D:\SPT400_assembly (decompiled SPT 4.0 Assembly-CSharp), 2026-07-03:

- **Brain**: BotOwner aggregates ~120 components; `StandartBotBrain.Activate()` has a hardcoded switch mapping `WildSpawnType` → brain class (GClass3xx). Each brain = priority-sorted list of `AICoreLayerClass` layers; first layer whose `ShallUseNow()` returns true wins, returns a `BotLogicDecision` (170+ enum values). `AICoreControllerClass.Update()` (called from `BotsController.method_0`) ticks all agents; vision is frame-sliced via AITaskManager (`EAITaskGroupType.LookSensor`), hearing is event-driven (`BotEventHandler.OnSoundPlayed`).
- **Navigation**: no NavMeshAgent anywhere — `NavMesh.CalculatePath` + manual steering (`BotPathFinderClass` → `PathControllerClass` → `BotMover` writing MovementContext). Strategic fallback routes through the AICorePoint graph (BFS/DFS in `BotPathFinderClass.smethod_4`, depth cap 20). No OffMeshLink usage at all. Doors = `NavMeshDoorLink` with three NavMeshObstacle carvers (Opened/Breached/Closed) toggled on door state; registry in `AIDoorsHolder`. See [[eft-navmesh-and-waypoints]].
- **Scene-baked AI data (the custom-map checklist)**: `BotZone` (MonoBehaviour, found via `LocationScene.GetAllObjects<BotZone>` in LocalGame.cs:104) with child `SpawnPointMarker`s and `PatrolWay`/`PatrolPoint`s; `AICoversData` root with `AICorePointHolder`, `AIManualPointsHolder` (GroupPoints), `AIVoxelesData` (serialized `VoxelsList` voxel grid), `AIPlaceInfoHolder`, `AIDangerPlacesHolder`, `AIMinesPositionsHolder`, `AIPatrolsData` (loot points, exfil points). Holders auto-create if missing (`CreateOrFind`) but **empty** — there is no runtime baker in the shipped assembly; `RestoreData`/`CachePoints` only rewire serialized IDs to objects. Cover/core/voxel data must be authored or generated by a mod.
- **Failure modes**: no BotZones → `BotsController` sets `CanSpawn = false`; zone with 0 spawn points filtered out (BotsController.cs:214-227); PatrolWay with 0 points → zone `IsValid()` false; boss wave `BossZone` name not matching any `BotZone.NameZone` → falls back to random marked boss zone (BossLocationSpawn.cs:289).
- **Server side**: waves/MinMaxBots/OpenZones/BossLocationSpawn/BotLocationModifier all come from the location JSON, resolved against scene zones by name string at raid start.

STATUE-BOT ROOT CAUSE (solved 2026-07-22, caught live by the stepwise method_10 witness):
- Follower joins a boss → formation slot → `PatrolPoint.GetSubPoint(index)`. GENERATED
  patrol points ship with ZERO sub-points (retail bakes ~6 formation offsets per point) →
  `Mathf.Clamp(index, 0, -1)` on an empty list returns **-1** → ArgumentOutOfRange →
  BotOwner.method_10's internal try{} swallows it → the rest of activation is skipped →
  statue (BotState=ActiveFail, standing rogues). Any group-spawned follower could hit it.
- Fix (IcebreakerCompatPatches.cs): at raid start call `point.CreateSubPoints(way)` for
  every 0-sub point — the game's OWN generator (non-SubManual path navmesh-samples ~6
  offsets); plus GetSubPoint prefix returning the point itself when the list is empty.
- Lesson for ANY generated AI bake: patrol points need sub-points, or every boss escort
  formation on the map is a statue lottery.
- Also: bots ROLL Mind.CHACE_TO_DEACTIVATE (default 100!) to defuse spotted tripwires, and
  tripwires from non-player owners auto-expire after TripwiresGlobalSettings.InertSeconds
  (300s) via method_3 — both patched off for authored icebreaker wires.

Baker-RE findings (verified 2026-07-03):
- **Voxel format fully specced**: hardcoded cells 10m(X) x 5m(Y) x 10m(Z) (`NavGraphVoxelBase` SIZE/SIZE_Y); index = floor((pos - MinVoxelesValues)/cellsize), clamped (`AICoversData.GetIndexes`:398). Serialized per voxel: Position (min corner), IndexX/Y/Z (ushort), Id, PointsIds, _closetsPointId, DoorLinksIds, LootPointsIds, ExfiltrationPointsIds, EntrancesIds, HaveNavMesh. Grid: VoxelsList + MinVoxelesValues + MaxVoxelesValues on AIVoxelesData. All object refs rebuilt at load from IDs.
- **GroupPoint contract**: needs Position (on navmesh), non-zero WallDirection (hide check = enemy within ~10 deg cone of WallDirection → point useless, GClass394.cs:74), FirePosition (default pos + 1.272 up), CoverLevel (Stay/Sit/Lay), CorePointId + ConnectionGroup (= corePoint.ConnectionGroupId, connected-component id), DefenceLevel = 64 - sum of 8-direction raycast scores from pos+1.26up, 8m max (CoverPointDefenceInfo.cs:36).
- **Shipped authoring code**: `CoverPointCreatorPreset.cs` = BSG's cover-generator tuning constants (generator itself editor-only, missing). `NavGraphContainer` + NavGraphEditorPoint/Path/PointWay + GClass421 (A*) + NavGraphVoxelCreatorTester etc = BSG's in-editor nav-graph toolkit, shipped and callable, incl. voxel grid construction from point bounds (method_0/method_3, bounds math at :483/:573). `AIManualPointsHolder.AddPoint/TryConnect` inserts new GroupPoints at runtime, wiring GroupPointPath via NavMesh.CalculatePath — the natural API for a runtime baker. `PatrolPoint.CreateSubPoints` = runtime sub-point generation (existence proof). `NavMeshDoorLink.TryCreateCrave` builds door carvers at runtime.
- **Only true gap**: the geometry scanner that proposes cover points (raycast walls → GroupPoint candidates) — must be reimplemented, guided by CoverPointCreatorPreset constants; plus ConnectionGroupId assignment (flood-fill over CalculatePath reachability).

Ground truth from dumps (factory4_day: 2669 pts/5 core/10178 ways/840 voxels; Sandbox_high: 5948/31/23570/7830), via [[ai-data-dumper-project]]:
- wallDirection always unit-length + horizontal (|y|~0); zero only on alwaysGood points (GZ: 109 zero ≈ 110 alwaysGood). firePosition = position + 1.272up for ~90% of points, rest add ~1.2-1.3m horizontal (corner-peek). altPosition NEVER used; special always 0; coverType ~all Wall; CoverLevel only Stay/Sit (no Lay).
- spacing: NN median ~1.0-1.2m, p95 ~2.4-3m; density ~15 pts/100m2 indoor (Factory) vs ~6.8 outdoor (GZ). defenceLevel observed 0-52 of theoretical 64.
- ways 100% reciprocal, dist = navmesh path length (median stretch 1.02-1.04 vs euclidean), degree mean ~3.9 (max 40), few long links up to 220m. Pathes list EMPTY at runtime — ways are the real edges.
- core points are coarse region nodes (~1 per 400-700 group points on Factory, ~1 per 200 on GZ), degree 0-4; connectionGroup ids not contiguous (Factory single group id=5; GZ groups 29/30 = tiny sniper islands, 31 = main).
- voxel grid is DENSE (VoxelsList = full MaxX*MaxY*MaxZ grid, exactly 840 and 7830), position = min + idx*cellsize holds exactly, point membership 100% consistent; closestPointId set only for cells with points.
- manualPoints empty on BSG maps. analysis script: Desktop\ManimalAIDataDumper\analysis\analyze_dump.py.
